# موقع إحصائيات فلسطين اليومية

موقع تفاعلي يعرض بيانات وإحصائيات يومية عن فلسطين، بما في ذلك:
- غزة والضفة الغربية
- عدد الشهداء والمصابين
- شهداء الأطفال والنساء
- الصحفيين المستهدفين
- الفرق الطبية المستهدفة
- معلومات تاريخية ومختصرات عن فلسطين

## التقنيات المستخدمة
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Fetch API)
- خطوط Google Fonts (Cairo)

## مميزات الموقع
- واجهة جذابة و UI/UX متطور
- خلفية داكنة مناسبة للعرض
- بطاقات معلوماتية لكل نوع من البيانات
- قائمة اختيار لتحديد التاريخ وعرض الإحصائيات اليومية
- استجابة كاملة لجميع أحجام الشاشات (Responsive)
- تأثير Hover على البطاقات لإظهار تفاعل المستخدم

## الأقسام
- **الرئيسية (Home):** صفحة رئيسية تعرض روابط لجميع الأقسام.
- **غزة (Gaza):** إحصائيات يومية عن غزة.
- **الضفة الغربية (West Bank):** بيانات يومية عن الضفة الغربية.
- **الصحفيين (Press):** معلومات عن الصحفيين المستهدفين.
- **معلومات عن فلسطين (About):** نبذة عن المشروع وأهدافه.

## كيفية الاستخدام
1. افتح الملف `index.html` في متصفحك.
2. اختر التاريخ من القائمة لعرض البيانات اليومية.
3. تصفح الأقسام المختلفة من شريط التنقل أو الأزرار.

## الهدف من المشروع
رفع الوعي بالوضع الإنساني في فلسطين ونشر بيانات دقيقة حول الأحداث اليومية بطريقة واضحة ومرتبة.
